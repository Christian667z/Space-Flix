Questions fréquentes

SpaceFlix est-il gratuit ?

Oui. Vous pouvez naviguer et regarder des contenus directement depuis un navigateur web sans créer de compte ni payer d'abonnement.

Comment fonctionne la reprise de lecture ?

Dès que vous regardez une vidéo, votre position est automatiquement mémorisée. Vous pouvez reprendre la lecture au moment exact sur tout appareil.

Quelles langues sont disponibles ?

De nombreux titres sont proposés en français (VF) ou en version originale sous-titrée (VOSTFR) avec choix de serveurs multiples.

Comment lancer un film ou une série ?

Cliquez simplement sur l'affiche du titre qui vous intéresse pour ouvrir immédiatement le lecteur vidéo haute définition et choisir votre serveur de streaming.

Pour en savoir plus, consultez la page À propos ou lisez la Politique de confidentialité et les Conditions d'utilisation.

— SUPABASE SQL EDITOR

Script SQL pour Reprise & Authentification

Copiez ce script et collez-le dans Supabase > SQL Editor > New Query > Run pour configurer la base de données de reprise de lecture, profils, favoris et historique. 

-- Table Reprise de lecture & Historique
CREATE TABLE IF NOT EXISTS public.user_history (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    media_id TEXT NOT NULL,
    media_title VARCHAR(255),
    media_type VARCHAR(20) DEFAULT 'movie',
    poster_url TEXT,
    season_number INT DEFAULT 1,
    episode_number INT DEFAULT 1,
    episode_title VARCHAR(255),
    current_time_seconds NUMERIC(10, 2) DEFAULT 0,
    duration_seconds NUMERIC(10, 2) DEFAULT 0,
    progress_percent INT DEFAULT 0,
    completed BOOLEAN DEFAULT false,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT unique_user_media_playback UNIQUE(user_id, media_id, season_number, episode_number)
);

ALTER TABLE public.user_history ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can manage history" 
ON public.user_history FOR ALL USING (auth.uid() = user_id);
